## Notas

- La API antigua por cabecera `Ocp-Apim-Subscription-Key` sola da 404;
  la key va como parámetro `apikey=` (o ambas). SOAP/POX se retiran el
  31-ago-2026; el endpoint vigente es el JSON/REST.
- Para automatizar: un script puede leer la key con
  `security find-generic-password -s bing-webmaster-api-key -w`, llamar a
  estos métodos y guardar los JSON con fecha (aquí o, por la convención
  de exports, en `admin/seo/` si la sesión dueña lo mueve).
